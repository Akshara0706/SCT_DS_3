# SCT_DS_3 - Bank Marketing Decision Tree Classifier

## Description
This project implements a Decision Tree Classifier to predict whether a customer will subscribe to a bank product or service using the UCI Bank Marketing dataset. The workflow includes downloading the dataset, preprocessing categorical features, training the model, and evaluating its performance.

## Features
- Automatic dataset download from the UCI repository
- Data preprocessing using one-hot encoding
- Train-test split for model evaluation
- Decision Tree model using Scikit-learn
- Accuracy, classification report, and confusion matrix generation

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Requests
- ZipFile
- NumPy

## Dataset
UCI Bank Marketing Dataset:
https://archive.ics.uci.edu/dataset/222/bank+marketing
